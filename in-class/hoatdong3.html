"Data Collector" - Thu thập dữ liệu đa dạng

Mục tiêu: Thu thập dữ liệu từ các loại Input đa dạng: Text (Họ tên), Radio button (Giới tính: Nam, Nữ, Khác), Checkbox (Sở thích: chọn nhiều mục mảng Array), và Select (Tỉnh/Thành phố). Tổng hợp thành một đối tượng JavaScript (Object) hoàn chỉnh có cấu trúc sạch.

Đối Tượng Dữ Liệu JavaScript Hoàn Chỉnh 0 sở thích được chọn 
// Nhấn nút "Đóng Gói Thành Object" để xem kết quả tại đây...

Kỹ thuật lấy dữ liệu Radio & Checkbox: 

// 1. Radio (Lấy mục duy nhất được checked):
const selectedGender = document.querySelector('input[name="gender"]:checked')?.value;

// 2. Checkbox (Lấy danh sách các mục được checked thành Array):
const selectedHobbies = Array.from(document.querySelectorAll('input[name="hobbies"]:checked'))
                             .map(checkbox => checkbox.value);
