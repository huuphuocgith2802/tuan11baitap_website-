"Smart Validator" - Bộ kiểm tra thông minh

Mục tiêu: Xây dựng Form đăng ký có kiểm soát lỗi thông minh:

  • Nếu Username ít hơn 5 ký tự: hiển thị lỗi "Tên quá ngắn (tối thiểu 5 ký tự)" vào thẻ <span class="error-msg"> và đổi border sang màu đỏ.
  • Nếu ô Email không chứa ký tự "@": hiển thị lỗi màu đỏ ngay bên dưới.
  • Nếu ô Mật khẩu để trống: hiển thị lỗi màu đỏ yêu cầu nhập mật khẩu.

Prompt Mẫu Yêu Cầu AI (Syllabus)

"Viết mã JS để kiểm tra một Form: Nếu ô 'username' ít hơn 5 ký tự, hãy hiển thị lỗi 'Tên quá ngắn' vào một thẻ span có class 'error-msg' và đổi border của input sang màu đỏ."

Cơ chế xử lý đổi border và hiển thị lỗi: 

function setError(input, errorSpan, message) {
  input.classList.remove('input-success');
  input.classList.add('input-error'); // Thêm viền đỏ
  errorSpan.textContent = message;    // Hiển thị nội dung lỗi
}

function setSuccess(input, errorSpan) {
  input.classList.remove('input-error');
  input.classList.add('input-success'); // Thêm viền xanh
  errorSpan.textContent = '';          // Xóa thông báo lỗi
}
