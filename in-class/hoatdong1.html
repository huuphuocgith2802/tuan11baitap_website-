"Stop the Page!" - Chặn tải lại trang

Mục tiêu: Tạo một Form đơn giản. Khi người dùng nhấn nút "Gửi Dữ Liệu", sử dụng event.preventDefault() để ngăn chặn hành vi tải lại trang mặc định của trình duyệt, giữ nguyên trạng thái ứng dụng và trích xuất dữ liệu in ra Console.

Vibe Coding Q&A (Hỏi Đáp Với AI)

Câu hỏi: "Tại sao tôi cần dùng preventDefault() khi xử lý Form bằng JavaScript?"
Trả lời: Mặc định khi bấm Submit, trình duyệt sẽ gửi HTTP request lên server và làm tải lại (reload) toàn bộ trang. Nếu trang bị tải lại, các biến JavaScript, DOM state, và dữ liệu người dùng đang nhập sẽ bị mất sạch! preventDefault() giúp chặn reload, trao quyền cho JS kiểm tra dữ liệu hoặc gửi qua Fetch/AJAX mà không giật trang.

Console Log Viewer (Mô phỏng trình duyệt) Sẵn sàng lắng nghe
[Hệ thống]: Đang chờ sự kiện submit từ Form... Nhấn nút "Gửi Dữ Liệu" để kiểm chứng!

Mã nguồn JavaScript cốt lõi: 

const form = document.querySelector('#stopPageForm');
form.addEventListener('submit', function (event) {
  // 1. Chặn hành vi tải lại trang mặc định
  event.preventDefault();

  // 2. Lấy giá trị input
  const name = document.querySelector('#fullName').value;
  const message = document.querySelector('#userMessage').value;

  // 3. In ra console an toàn
  console.log("Dữ liệu gửi lên:", { name, message });
});
