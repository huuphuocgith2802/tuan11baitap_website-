Khóa Nút Submit (Disabled / Enabled Toggling)

Yêu cầu đề bài: Nút "Gửi Đơn Đăng Ký" sẽ bị vô hiệu hóa (disabled và mờ đi) cho đến khi người dùng tick vào ô checkbox "Tôi đồng ý với điều khoản dịch vụ". Khi bỏ chọn, nút sẽ tự động bị khóa trở lại.

Điều khoản dịch vụ sử dụng hệ thống LHU Portal:

1. Người dùng cam kết cung cấp thông tin chính xác và chịu trách nhiệm về tính xác thực của dữ liệu cá nhân.

2. Dữ liệu được bảo mật theo tiêu chuẩn quy định của Nhà trường và Luật An ninh mạng.

3. Nghiêm cấm các hành vi tấn công từ chối dịch vụ (DDoS), chèn mã độc hại (XSS, SQL Injection) vào Form nhập liệu.

Logic JavaScript điều khiển thuộc tính disabled: 

const checkbox = document.getElementById('agreeCheckbox');
const submitBtn = document.getElementById('submitBtn');

checkbox.addEventListener('change', function () {
  // Nếu checkbox được tick (checked === true), disabled = false (Mở khóa)
  // Nếu bỏ tick (checked === false), disabled = true (Khóa lại)
  submitBtn.disabled = !this.checked;
});
